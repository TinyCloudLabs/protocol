# Identity

Owner and session identities — DIDs, SIWE sign-in, and OpenKey.

## Concepts

- [DIDs](dids.md) — Owner did:pkh:eip155 root authority plus ephemeral Ed25519 did:key session keys.
- [Sign-In with Ethereum](siwe.md) — SIWE sign-in establishes root authority and bootstraps session delegations.
- [Session Keys](session-keys.md) — Ephemeral Ed25519 did:key session keys delegated to from the owner root authority.
- [OpenKey](openkey.md) — Passkey/TEE-backed identity provider: owner keys, the primary key, and consent for apps, CLIs, and agents.
- [Device Authorization](device-authorization.md) — Approve a CLI or agent session on another device, bounded to KV access in one space.
